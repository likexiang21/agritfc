## 2. 主要修复（按系统）

### 2.1 作物与收获

- 统一收获器传入 `level.getBlockEntity(pos)`，修复 TFC `crop_yield_uniform` 读不到 `CropBlockEntity` 导致 95 个 A/TFC 非谷类作物主产物为 0；
- B 香料/草莓作物改继承 `TfcFarmlandCropBlock`，同时接受 vanilla farmland 与 `#tfc:farmlands`；
- `CropPropagation` 取消 `tfc:` 前缀豁免，TFC 种子进入同一传播表并补 TFC/A 分类；
- 播种门、种子处理、育苗盘的耕地判断统一使用 `TFCTags.Blocks.FARMLANDS`；
- 种子处理 boost 对 A/TFC 使用 `CropHelpers.growthTickStep`，不再直接 `setGrowth`；
- 育苗/球茎/根茎放置前检查 `canBeReplaced`，避免覆盖已有方块；
- TFC `*_bush_cane`、wintergreen、非 FRUITING 草莓、`wild_crop` 的废枝叶补漏。

### 2.2 食物、副产物与堆肥

- 82 个 `crop_waste`、10 个 `bush_waste`、20 个 `spice_waste`、`wet_grass`、8 个 `nut_shell` 接入 TFC 堆肥标签；
- 为 8 坚果、8 坚果粉、15 野生蘑菇补 31 个 TFC `FoodDefinition`，使它们真正可食用；
- 锅/餐盘/可放置食物的份数、创造模式、腐败/腐烂和掉落规则修复；
- 餐盘/可放置食物 `getDrops` 使用 loot 上下文捕获的 BE，避免方块已移除后丢物品。

### 2.3 TFC / Firmalife

- TFC 种子不再被育苗盘拒绝；`SeedlingItem` 可解析 `tfc:crop/<species>`；
- Firmalife 20 个非 potted `plant/*` + 2 个 `grape_string_plant_*` 全部接入 B 废枝叶链；
- Firmalife 香草保持刀具门槛且不重复掉 B 产物；
- 8 个香草以外的 14 个 Firmalife 植物新增 `crop_waste/*`。

### 2.4 其他设备与资源

- 厨房食物展示/水果盘改用 `FoodCapability.has`，接受 TFC/B 食物；
- 锅铲勺油 `tryFluidTransfer` 参数顺序修正；
- 烹饪锅自动化输入改走 `addIngredient`，不再产生“只进 inventory、不烹饪”的死数据；
- 菌包/育苗盘按 stage 使用不同模型；
- 干燥架/石臼/育苗盘/木料堆/可放置食物/蚕架增加 BER，内容物客户端可见；
- 菌包破坏时把 species/progress/uses 写入物品 `BLOCK_ENTITY_DATA`，重新放置可恢复；
- 世界生成 biome tag 加入 85 个陆生 TFC biome，修复 TFC 世界不生成蘑菇/坚果/香料树；
- lang 全部改为点号键；Firmalife 废枝叶图标/中文名、坚果叶挂果 overlay、香料树贴图、香料/草莓 age 模型已补；
- Firmalife 废枝叶增加创造模式守卫；客户端渲染自检计数修正。

### 2.5 本轮新增的视觉/数据修复

- 坚果叶 `nut_state=1/2/3` 增加挂果 overlay（3 个坚果树种）；
- 5 个香料树/树苗改用不同 TFC 树叶/树苗贴图；
- 15 个香料作物 + 草莓的 8 个 age、15 个野生蘑菇的 3 个 age 使用不同模型；
- 14 个 Firmalife 废枝叶改用 Firmalife 现有物品图标，zh_cn 名称中文化。
